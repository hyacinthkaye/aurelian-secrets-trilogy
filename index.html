World Guide - Border Customs

The Threshold Box Protocol

The border between Solaria and Aurelia is not only geographic. It is ritual, law, superstition, and memory. The threshold box exists because the first rule is absolute: objects only, never hands.

RULE I

NO SKIN MAY TOUCH

Contact across the border is treated as contamination, not intimacy. The law makes distance physical.

RULE II

OBJECTS ONLY

Messages, tokens, and official materials pass through sanctioned containers. Intent does not excuse procedure.

RULE III

HAND VEILS REQUIRED

Veils are not decoration. They are proof that the body did not claim what the border allowed to pass.

ARCHIVAL NOTE

The threshold box is one of the series' central images: a beautiful, bureaucratic object built to make longing obey the law.

Reader Guide - Spoiler Safe Themes

What The Series Is About

No plot turns, no ending explanations - only the emotional architecture of the world.

THEME FILE 01

PRESERVATION VS LIFE

Solaria grows. Aurelia endures. The series asks what is lost when a kingdom confuses survival with stillness.

THEME FILE 02

RECORDS AND MEMORY

The archives preserve fragments, but fragments are not the same as truth. Every record carries the pressure of the person who kept it.

THEME FILE 03

FORBIDDEN PROXIMITY

The romance lives inside restraint: veils, thresholds, rules, silence, and the danger of wanting what the world forbids.

THEME FILE 04

KINGDOMS AS WOUNDS

Solaria and Aurelia are not simple opposites. They are two answers to an old fracture, each beautiful, each incomplete.
